NOVA STORE - النسخة الكاملة
1) ارفع كل محتويات المجلد لمستودع GitHub (استبدل القديم كله).
2) Render: Build = npm install | Start = npm start
3) المتغيرات: TOKEN و OWNER_ID  (اختياري: BACKUP_TARGET_ID)
4) اكتب: اوامر   أو   /لوحة   (لوحة التحكم)
5) ادعُ البوت بصلاحية applications.commands عشان تظهر أوامر السلاش.


==================== لوحة التحكم (الموقع) ====================
1) في Render ← Environment أضف متغير:  DASHBOARD_PASSWORD  = كلمة سر قوية
   (اختياري) BACKUP_TARGET_ID = أيدي الروم/الشخص اللي تروح له النسخ (الافتراضي 1345715711095472280)
2) أعد النشر، ثم افتح رابط Render نفسه (https://اسم-بوتك.onrender.com) وادخل بكلمة السر.
3) من الموقع تتحكم بـ: الحسابات (إضافة/سحب/تجميد/تصفير)، الوظائف والرواتب، أوقات الأوامر والخبرة،
   نسب الفوز والسرقة، أسعار السوق (وتثبيتها)، المظهر (ألوان/صورة خلفية + معاينة حيّة تتحرك مع الألوان)،
   البريفكس، رومات الأوامر، حالة البوت، النسخ الاحتياطي والاسترجاع.
4) الخبرة: كل أمر بنك ينفّذ يعطيك XP، وإذا وصلت مستوى وظيفة جديدة يترقّى تلقائياً ويطلع إعلان.
5) لازم البوت يكون مدعوّ بصلاحية applications.commands عشان أوامر السلاش.
ملاحظة: Render المجاني ينام بعد 15 دقيقة، استخدم UptimeRobot على الرابط (/health).
